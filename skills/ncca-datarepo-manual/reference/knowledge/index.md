# 지식 인덱스

데이터 저장소를 구축하고 관리할 때 필요한 규칙, 규격, 작성 가이드 목록이에요.

## 내부 지식 문서 (OKF)

- [데이터 저장소 운영 및 구성 규칙](./repo-rules.md): 저장소 명명, 권한(`private`), 내부 의존성 금지 및 표준 디렉터리 구조 규칙이에요.
- [STAC 메타데이터 규격](./stac-spec.md): 시공간 데이터의 검색과 표준화를 위한 STAC `collection.json` 작성 규약이에요.
- [데이터 설명 문서 작성 규칙](./technical-writing.md): 신규 팀원을 위한 `README.md`(Dataset Card), 메타데이터 설명, 코드 주석 작성 지침이에요.

## 외부 참조 링크

- [Hugging Face Hub Repositories](https://huggingface.co/docs/hub/repositories): 저장소 생성, 권한 설정, Git LFS/Xet 프로토콜 기반 대용량 파일 관리 공식 문서예요.
- [STAC Specification](https://stacspec.org/en/about/stac-spec/): SpatioTemporal Asset Catalog 공식 사양 문서예요.
