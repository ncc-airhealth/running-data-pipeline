# Dataset Card 작성 매뉴얼

README.md 작성 메뉴얼입니다.

`collection.json`에 기록된 정보를 기반으로 작성해주세요.

## 작성 원칙

다음의 원칙은 반드시 지켜주세요!

- 확인한 사실만 작성하고, 알 수 없는 값은 추정하지 않음
- 원본 데이터와 가공 결과를 구분하고, 누가 생산하고 제공했는지 밝힘
- 저장소의 실제 파일명, 컬럼명, 좌표계와 STAC 메타데이터를 기준으로 설명
- 사용자가 데이터를 읽는 데 필요한 최소 예시는 실제 저장소 구조와 맞게 제공
- 품질 문제와 누락 범위, 갱신 지연, 사용할 때 주의할 점을 숨기지 않음
- 라이선스 이름만 적지 않고 원본 이용 조건과 가공·재배포 조건을 설명
