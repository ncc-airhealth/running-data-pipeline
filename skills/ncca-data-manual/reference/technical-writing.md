# 테크니컬 라이팅

STAC 메타데이터, Dataset Card, 코드 주석과 docstring에 짧고 자연스러운 한국어를 사용해요.
공식 출처의 의미를 유지하고 GIS 배경지식이 있는 사람을 대상으로 설명하세요.

## 문체와 문장

- 설명 본문은 해요체로 작성하세요.
- 독자에게 작업을 안내할 때는 `~하세요`로 작성하세요.
- 표나 목록으로 정보를 나열할 때는 명사형으로 간결하게 작성하세요.
- 한 문장에는 하나의 정보나 행동만 담으세요.
- 독자가 수행할 작업은 독자를 행동의 주체로 두고 능동형으로 작성하세요.
- 파이프라인이나 도구의 동작을 설명할 때만 해당 시스템을 문장의 주체로 사용하세요.
- 데이터의 사실, 조건, 제한을 바로 설명하세요.
- 모호한 범위나 정도 대신 확인된 조건, 수치, 단위를 작성하세요.
- 설명 본문에서는 불필요한 명사형 표현을 줄이고 실제 행동을 나타내는 동사를 사용하세요.
- 같은 종결 표현으로 사실을 반복해 나열하지 말고 관련된 내용을 묶어 설명하세요.
- 내용 없이 흐름만 알리는 표현과 불필요한 한자어·번역체·은어를 제거하세요.
- 같은 단계의 제목은 핵심 용어를 포함한 명사형으로 통일하세요.

## 용어와 표기

- 기술 용어는 공식 표기를 따르고 같은 개념에는 같은 용어를 사용하세요.
- 뜻이 모호한 용어는 원문을 함께 표기하세요.
- 영어 `product`에 해당하는 기술 용어는 `제품` 대신 `프로덕트`로 작성하세요.
- `리비전` 대신 문맥에 맞는 `버전`, `커밋 SHA`, `브랜치`, `태그`를 사용하세요.
- 대상 독자에게 낯선 약어는 처음 나올 때 전체 이름과 함께 작성하세요.

## 코드 주석과 docstring

- 주석과 docstring은 짧고 자연스러운 한국어로 작성하세요.
- 코드에 드러난 동작을 반복하지 말고 의도나 제약 조건을 설명하세요.

# AI 추가 지침

- 자연어의 내용과 글쓰기는 업무 담당자와 AI가 검토하세요.
- 자연어 표현을 기계적으로 검사하지 마세요.
