# Dataset Card (`README.md`) 작성 메뉴얼

## 체크리스트

### YAML metadata

- [ ] YAML metadata가 정상적으로 파싱된다.
- [ ] `pretty_name`, `license`, `tags` 등 실제로 사용하는 필드만 작성했다.
- [ ] 공간 데이터에 `geospatial` tag가 있다.
- [ ] `configs`와 `data_files`를 사용한다면 모든 경로가 실제 파일과 일치한다.
- [ ] 빈 값, placeholder, 확인하지 않은 metadata가 없다.

### 본문

- [ ] 한국어로 작성되었다. (도메인 용어는 예외)
- [ ] 데이터가 표현하는 대상과 파일 구성을 설명했다.
- [ ] 생산, 수집, 가공, 제공 주체와 원출처를 설명했다.
- [ ] 획득 방법, 시점, 버전과 원본 파일명을 기록했다.
- [ ] 사람이 직접 획득해야 한다면 재현 가능한 절차를 설명했다.
- [ ] 처리 과정 또는 처리하지 않은 이유를 설명했다.
- [ ] 데이터 사용 방법과 대표적인 읽기 방법을 설명했다.
- [ ] 품질, 오차, 알려진 한계와 주의사항을 설명했다.
- [ ] 라이선스, 가공·재배포 조건과 갱신 방법을 설명했다.
- [ ] 문서의 내부 경로와 외부 링크가 올바른 대상을 가리킨다.
