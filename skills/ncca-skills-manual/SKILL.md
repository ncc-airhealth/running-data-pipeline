# 데이터 파이프라인 작업 매뉴얼 작성 지침

NCCA 데이터 파이프라인 작업 매뉴얼(Agent Skill)의 구성과 작성 기준을 정한 지침입니다.

## 작업 매뉴얼의 역할

이 저장소에서는 업무 담당자와 AI 에이전트가 같은 절차와 판단 기준을 따르도록 작업 매뉴얼을 [Agent Skill](https://agentskills.io) 형식으로 관리합니다.

## 형식

작업 개요와 공통 지침은 `SKILL.md`에 작성하세요.
특정 단계에서만 필요한 상세 절차는 `reference/*.md`로 나누고, `SKILL.md`에서 해당 문서를 읽어야 하는 시점을 안내하세요.

본문은 아래 예시처럼 `#`으로 시작하는 제목 두 개로 나누어 작성하세요. 첫 번째에는 매뉴얼 제목을 쓰고, 두 번째는 `# AI 추가 지침`으로 작성하세요.

```md
# <문서 제목>

<업무 담당자가 읽고 수행할 수 있는 작업 매뉴얼 형식으로 작성>

# AI 추가 지침

<AI 에이전트에게만 필요한 지침(문체, 도구 선택, 허용된 작업, 사전 승인이 필요한 작업 등)을 작성>
```

> [!IMPORTANT]
> 작업 매뉴얼은 [Agent Skills 명세](https://agentskills.io/specification)에 따라 작성하세요.

## 작성 내용

작업 매뉴얼은 [Diátaxis의 How-to guides](https://diataxis.fr/how-to-guides/) 원칙에 따라 업무 담당자가 실제 작업 목표를 달성할 수 있는 행동 중심의 문서로 작성하세요.

> [!IMPORTANT]
> 문서 없이는 알 수 없는 프로젝트 고유의 절차와 판단 기준을 실제 작업 순서에 맞춰 작성하세요. 아래 항목은 고정 목차가 아니므로 작업에 필요한 내용만 작성하세요.

| 항목 | 담을 내용 |
|---|---|
| 작업 목표와 범위 | 업무 담당자가 달성할 구체적인 결과, 매뉴얼을 적용하는 상황, 포함하거나 제외할 작업 |
| 작업 전 준비 사항 | 필요한 자료와 설정값, 도구와 버전, 계정과 접근 권한, 작업 위치, 먼저 완료해야 할 작업, 준비 여부를 확인하는 방법 |
| 주의 사항 | 작업 전에 확인할 사항, 데이터 손실이나 잘못된 공개를 막기 위해 주의할 점 |
| 작업 절차 | 작업 순서, 단계마다 수행할 내용, 확인이 필요한 단계의 결과, 상황에 따라 달라지는 작업과 선택 기준, 필요한 명령어와 실행 위치 |
| 완료 체크리스트 | 작업이 끝났을 때 확인할 상태, 결과물의 위치와 형식, 확인 방법, 예상 결과와 통과 기준 |
| 문제 발생 시 조치 | 문제 확인 방법, 작업을 중단하거나 다시 시도하는 기준, 복구 방법, 해결되지 않을 때 알릴 대상 |

## 검토

- 전체 매뉴얼을 검토할 때는 `SKILL.md`와 연결된 문서를 모두 확인하세요.
- 일부 단계만 검토할 때는 해당 문서와 그 문서를 연결하는 `SKILL.md`의 안내를 함께 확인하세요.
- [Agent Skills 명세](https://agentskills.io/specification)를 준수하는지 확인하세요.
- 작업 목표를 달성하고 완료 여부를 확인하는 데 필요한 내용이 빠지지 않았는지 확인하세요.
- 경로, 링크, 명령어, 버전, 설정값이 실제 코드와 기준 문서에 맞는지 확인하세요.
- 같은 작업 조건에서 본문과 `AI 추가 지침`이 같은 절차와 완료 기준을 제시하는지 확인하세요.
- 판단이나 작업 결과에 영향을 주지 않는 내용은 제거하세요.
- 문제를 발견하면 수정한 뒤 같은 항목을 다시 확인하세요.

# AI 추가 지침

## 내용 작성

- AI 에이전트에게만 필요한 내용을 작성하고, 본문에서 정한 목적, 작업 순서, 완료 기준을 그대로 따름
- 개별 사례를 일반 지침으로 만들기 전에 코드, 기준 문서, 반복된 문제, 명시된 요구에서 근거 확인. 근거를 확인할 수 없는 프로젝트 정보는 추정하지 않음

## 한국어 사용

- 본문의 설명은 `~합니다`, 직접 지시는 `~하세요`로 작성. 제목과 항목명, `# AI 추가 지침`의 목록은 명사형으로 작성
- 영어 문장을 옮긴 듯한 어순을 피하고 자연스러운 한국어 어순 사용
- 뜻을 흐리는 외래어와 한자어는 짧고 익숙한 표현으로 교체 (`확인을 수행합니다` → `확인합니다`, `도구를 활용합니다` → `도구를 씁니다`)
- `적절히`, `효율적으로`, `충분히`처럼 판단을 미루는 말은 구체적인 조건이나 확인 기준으로 교체
