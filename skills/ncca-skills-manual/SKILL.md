# NCCA 스킬 작성 매뉴얼

데이터 파이프라인 프로젝트에서 반복적으로 수행하는 작업을 문서화하는 매뉴얼이에요.

사람과 AI 에이전트가 모두 **동일한 절차와 판단 기준으로 작업**할 수 있도록, [Agent Skills](https://agentskills.io/home.md) 기반의 기술문서 형식으로 매뉴얼을 작성하고 배포해요.

## 준비사항

매뉴얼을 작성하기 전 다음 문서들을 확인해 주세요.

- [Agent Skills 규격](https://agentskills.io/specification)
- [글쓰기 규칙](reference/knowledge/writing-style.md)
- [Open Knowledge Format (OKF)](reference/knowledge/open-knowledge-format.md)

## 작업 순서

다음 순서에 따라 매뉴얼을 작성해주세요.

1. [1. 뼈대 세우기](reference/1-framework.md)  
2. [2. 워크플로우 설계하기](reference/2-workflow.md)  
3. [3. 지식 문서화하기](reference/3-knowledge.md)  
4. [4. 개요 작성하기](reference/4-outline.md)  
5. [5. 작업 기술하기](reference/5-describe.md)  
6. [6. 매뉴얼 검토·배포](reference/6-publish.md)  

> **AI 추가 지침**
>
> - [준비사항](#준비사항)의 문서들을 숙지하고 매뉴얼 작성을 시작할 것
> - [작업 순서](#작업-순서)에 따라 사용자를 인터뷰하며, 단계별로 제안하고 승인을 받아 매뉴얼을 작성할 것
