# 데이터 파이프라인 작업 매뉴얼 작성 지침

NCCA 데이터 파이프라인 작업 매뉴얼(Agent Skill)의 구성과 작성 기준을 정한 지침이에요.  
이 저장소에서는 업무 담당자와 AI 에이전트가 같은 절차와 판단 기준을 따르도록 작업 매뉴얼을 [Agent Skill](https://agentskills.io) 형식으로 관리해요.

## 형식

작업 개요와 공통 지침은 `SKILL.md`에 작성해요.
특정 단계에서만 필요한 상세 절차는 `reference/*.md`로 나누고, `SKILL.md`에서 해당 문서를 읽어야 하는 시점을 안내하세요.

본문은 아래 예시처럼 `#`으로 시작하는 제목 두 개로 나누어 작성해요. 첫 번째에는 매뉴얼 제목을 쓰고, 두 번째는 `# AI 추가 지침`으로 작성하세요.

```md
# <문서 제목>

<업무 담당자가 읽고 수행할 수 있는 작업 매뉴얼 형식으로 작성>

# AI 추가 지침

<AI 에이전트에게만 필요한 지침(문체, 도구 선택, 허용된 작업, 사전 승인이 필요한 작업 등)을 작성>
```

> [!IMPORTANT]
> 작업 매뉴얼은 [Agent Skills 명세](https://agentskills.io/specification)에 따라 작성하세요.

## 작성 내용

작업 매뉴얼은 [Diátaxis의 How-to guides](https://diataxis.fr/how-to-guides/) 원칙에 따라 업무 담당자가 실제 작업 목표를 달성할 수 있는 행동 중심의 문서로 작성해요.

> [!IMPORTANT]
> 문서 없이는 알 수 없는 프로젝트 고유의 절차와 판단 기준을 실제 작업 순서에 맞춰 작성하세요. 아래 항목은 고정 목차가 아니므로 작업에 필요한 내용만 작성하세요.

| 항목 | 담을 내용 |
|---|---|
| 작업 목표와 범위 | 업무 담당자가 달성할 구체적인 결과, 매뉴얼을 적용하는 상황, 포함하거나 제외할 작업 |
| 작업 전 준비 사항 | 필요한 자료와 설정값, 도구와 버전, 계정과 접근 권한, 작업 위치, 먼저 완료해야 할 작업, 준비 여부를 확인하는 방법 |
| 주의 사항 | 작업 전에 확인할 사항, 데이터 손실이나 잘못된 공개를 막기 위해 주의할 점 |
| 작업 절차 | 작업 순서, 단계마다 수행할 내용, 확인이 필요한 단계의 결과, 상황에 따라 달라지는 작업과 선택 기준, 필요한 명령어와 실행 위치 |
| 완료 체크리스트 | 작업이 끝났을 때 확인할 상태, 결과물의 위치와 형식, 확인 방법, 예상 결과와 통과 기준 |
| 문제 발생 시 조치 | 문제 확인 방법, 작업을 중단하거나 다시 시도하는 기준, 복구 방법, 해결되지 않을 때 알릴 대상 |

## 글쓰기 원칙

작업 매뉴얼은 명확하고 간결하며 자연스러운 한국어로 작성하고, 문체와 용어를 일관되게 사용하세요.

아래 규칙은 [토스 테크니컬 라이팅 가이드](https://github.com/toss/technical-writing)를 참고하여 작업 매뉴얼에 맞게 정리한 기준이에요.

### 문체와 문장

- 본문의 설명에는 해요체를 권장해요.
- 업무 담당자에게 직접 지시할 때는 `~하세요`로 작성하세요.
- 한 문장에는 하나의 정보나 행동만 담고, 서로 독립된 내용은 문장을 나누세요.
- 작업의 주체와 행동을 분명히 쓰세요.
- 수동형보다 능동형을 사용하세요.
- 도구나 시스템 자체의 동작을 설명할 때는 해당 도구나 시스템을 주체로 쓰세요.
- 불필요한 한자어와 영어식 명사형 표현을 줄이고, 실제 행동이 드러나는 동사로 작성하세요.
- 은어나 직역한 표현 대신 실제 동작과 결과를 설명하세요.
- 문서의 흐름을 설명하거나 내용을 불필요하게 강조하는 표현은 삭제하세요 (`앞서 설명했듯이`, `이제 알아보겠습니다`, `결론적으로` 등).

### 표현과 표기

- 기술 용어는 공식 문서의 표기를 따르고, 같은 개념에는 같은 용어를 사용하세요.
- 대상 독자에게 익숙하지 않은 약어는 처음 등장할 때 전체 이름과 함께 작성하세요.
- 모호한 표현 대신 적용 조건, 대상, 수치, 단위, 예상 결과를 구체적으로 작성하세요.
- 근거를 확인할 수 없는 조건, 수치, 예상 결과는 추정하지 마세요.
- 제목에는 독자가 찾을 핵심 용어를 포함하고, 명사형으로 통일하세요.

## 검토

- 전체 매뉴얼을 검토할 때는 `SKILL.md`와 연결된 문서를 모두 확인하세요.
- 일부 단계만 검토할 때는 해당 문서와 그 문서를 연결하는 `SKILL.md`의 안내를 함께 확인하세요.
- [Agent Skills 명세](https://agentskills.io/specification)를 준수하는지 확인하세요.
- 작업 목표를 달성하고 완료 여부를 확인하는 데 필요한 내용이 빠지지 않았는지 확인하세요.
- 경로, 링크, 명령어, 버전, 설정값이 실제 코드와 기준 문서에 맞는지 확인하세요.
- 같은 작업 조건에서 본문과 `AI 추가 지침`이 같은 절차와 완료 기준을 제시하는지 확인하세요.
- `글쓰기 원칙`에 따라 문체와 용어가 일관되는지 확인하세요.
- 각 절차에서 누가 무엇을 해야 하는지, 언제 적용하는지, 어떤 결과로 완료를 판단하는지 확인하세요.
- 판단이나 작업 결과에 영향을 주지 않는 내용은 제거하세요.
- 문제를 발견하면 수정한 뒤 같은 항목을 다시 확인하세요.

# AI 추가 지침

## 내용 작성

- AI 에이전트에게만 필요한 내용을 작성하세요.
- 본문에서 정한 목적, 작업 순서, 완료 기준을 그대로 따르세요.
- 개별 사례를 일반 지침으로 만들기 전에 코드, 기준 문서, 반복된 문제, 명시된 요구에서 근거를 확인하세요.
- 근거를 확인할 수 없는 프로젝트 정보는 추정하지 마세요.
