# 작업 매뉴얼과 Skill 작성 지침

데이터 파이프라인 프로젝트의 작업 메뉴얼(Agent Skill)을 작성하거나 수정할 때 적용하는 지침입니다.

## 작성 규칙

- [Agent Skills specification](https://agentskills.io/specification)을 준수
- 한국어로 작성, 도메인 용어는 영어를 허용
- 명령어, 코드, 경로는 정확히 표기
- 쉽게 읽을 수 있게 작성
- 재현가능성을 고려하여 작성
- 같은 지침을 여러 파일에 중복하여 작성하지 않음
- 스킬 추가 또는 수정 후 폴더 이름, frontmatter의 `name`, 본문의 경로와 명령어가 일치하는지 확인
- 본문은 `# <매뉴얼 이름>`과 `# AI 추가 지침`으로 나누어 작성
  - `# <매뉴얼 이름>`: 사람이 읽음, 존댓말로 작성
  - `# AI 추가 지침`: AI 에이전트가 읽음, 개조식으로 작성, 명사형 어미 사용

# AI 추가 지침

- 기본적으로 한국어로 작성
- `# <매뉴얼 이름>` 섹션에는 사람과 에이전트가 함께 따라야 하는 절차와 규칙을 작성
- `# AI 추가 지침` 섹션 에이전트에게 적용되는 제약과 판단 기준을 추가 작성
- 자연스러운 한국어 문체를 사용 (초안을 작성 후 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 `humanize-korean` 스킬로 문체 점검 권장)
