## 세부 작업 문서 템플릿

각 세부 작업 문서는 다음 템플릿을 기반으로 작성해요.

```md
# {{ 번호 }}. {{ 작업명 }}

{{ 작업에 대한 간략한 한 줄 소개 }}

## 세부 절차

1. {{ 구체적인 첫 번째 행동 }}
2. {{ 구체적인 두 번째 행동 }}

## 완료 조건

다음 조건을 모두 만족하면 작업이 완료돼요.

- [ ] {{ 검증 가능한 완료 조건 1 }}
- [ ] {{ 검증 가능한 완료 조건 2 }}

> **AI 추가 지침**
>
> - {{ AI가 준수해야 할 주의사항 및 사용자 승인 요구 사항 }}

---
다음 작업: [{{ 다음 번호 }}. {{ 다음 작업명 }}](./{{ 다음문서 }}.md)
```

## 5-1. 파일 생성 및 제목 작성하기

`reference/` 디렉터리에 `[번호]-[kebab-case-작업명].md` 형식으로 파일을 생성해요.

- 파일명 예시: `reference/1-boil-water.md`, `reference/2-cook.md`
- 문서 최상단에 `# {{ 번호 }}. {{ 작업명 }}`으로 제목을 쓰고, 작업의 목적이나 역할을 한 문장으로 소개해 주세요.

> **AI 추가 지침:** 사용자에게 파일 경로와 문서 제목을 제안하고 생성을 진행할 것

## 5-2. 세부 절차 작성하기

목표를 달성하기 위해 실행해야 하는 행동을 번호 목록(`1.`, `2.`)으로 순서대로 작성해요.

- [글쓰기 규칙](./knowledge/writing-style.md)에 따라 직접적인 행동 지시는 `~하세요`, `~해주세요` 어조를 사용해요.
- 명령어, 실행 코드, 경로 등이 필요한 경우 코드 블록을 제공하세요.

```markdown
예시:
## 세부 절차

1. 계량컵을 이용해 물 550ml를 냄비에 부으세요.
2. 가스레인지 또는 인덕션의 화력을 강불로 켜세요.
3. 물이 완전히 끓어오를 때까지 뚜껑을 덮고 기다리세요.
```

> **AI 추가 지침:** 사용자와 상호작용하며 실제 실행에 필요한 단계별 지시문과 명령어를 정리해 제안할 것

## 5-3. 완료 조건 작성하기

작업 절차를 모두 수행한 후, 해당 작업이 성공적으로 끝났음을 검증할 수 있는 기준을 문서의 마지막 목차에 체크리스트(`- [ ]`) 형태로 작성해요.

```markdown
예시:
## 완료 조건

다음 조건을 모두 만족하면 작업이 완료돼요.

- [ ] 냄비에 물 550ml가 담겨 있음
- [ ] 물이 기포를 내며 100℃로 끓고 있음
```

> **AI 추가 지침:** 사용자에게 절차 수행 후 정상 완료를 확인할 수 있는 구체적인 산출물이나 상태 조건을 질문할 것

## 5-4. AI 추가 지침 및 이동 링크 작성하기

- **AI 추가 지침**: AI 에이전트와 페어링할 때 특별히 주의해야 하거나 사용자의 명시적 승인이 필요한 작업이 있다면 `> **AI 추가 지침**` 블록을 작성해요.
- **이동 링크**: 문서 맨 하단에 다음 단계 문서로 이동할 수 있는 상대 경로 링크를 작성해요.  
  (마지막 세부 작업 문서인 경우 [6. 매뉴얼 검토·배포](./6-publish.md)로 링크를 연결해요.)
