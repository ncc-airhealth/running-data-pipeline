# 3. 지식 문서화하기

작업 매뉴얼을 작성하고 있다면, 해당 작업에 익숙한 상태일거에요.
하지만 작업을 하며 암묵적으로 사용되었던 `지식`이 존재할거에요.
해당 지식을 모르는 이가 작업을 잘 해낼 수 있게 문서화해주세요.

### 목차

[3-1. 지식 나열하기](#3-1-지식-나열하기)  
[3-2. 지식 구조화하기](#3-2-지식-구조화하기)  

## 3-1. 지식 나열하기

다음의 예시처럼, 작업을 하며 당연하게 사용했던 지식을 찾아요.

> 예시: 라면을 끓이는 상황
>
> - (개념/용어) [끓는점](https://ko.wikipedia.org/wiki/%EB%81%83%EB%8A%94%EC%A0%90) (물이 기포를 내며 끓어오르는 온도)
> - (규칙) "물은 계량컵으로 정량 550ml를 맞춘다"
> - (규칙) "물이 완전히 끓어오른 뒤에 면과 스프를 넣는다"

> **AI 추가 지침:** 사용자에게 작업의 세부사항에 대해 하나씩 질문하며, 암묵적으로 요구되는 지식과 규칙을 제안할 것

## 3-2. 지식 구조화하기

[3-1](#3-1-지식-나열하기)에서 찾은 지식들을, 매뉴얼을 읽는 이가 이해할 수 있도록 문서를 작성하고 인덱스에 등록해요.

- 지식 문서는 [Open Knowledge Format (OKF)](./knowledge/open-knowledge-format.md) 규약에 따라 `reference/knowledge/` 경로에 작성해요.
- 이미 잘 작성된 공식문서가 웹 상에 존재한다면, 문서를 새로 만들지 않고 해당 링크로 대체해요.
- 작성이 완료된 문서는 [지식 인덱스](./knowledge/index.md)에 추가해요.

> **AI 추가 지침:** `reference/knowledge/`에 문서를 하나씩 작성하고 사용자에게 검토 및 승인을 요청할 것
