# NCCA 매뉴얼 글쓰기 규칙

사람과 AI 에이전트가 동일한 절차와 기준으로 작업할 수 있도록 돕는 글쓰기 규칙이에요.  
[토스 테크니컬 라이팅 가이드](https://github.com/toss/technical-writing)를 참고하여 NCCA 작업 매뉴얼 환경에 맞게 정리했어요.

## 1. 핵심 원칙

- **사람과 AI 모두를 위한 명확성**: 사람에게 읽기 쉬운 문장은 AI 에이전트에게도 이해하기 쉬워요. 주어와 목적어, 행동을 분명하게 밝히세요.
- **단문 위주 작성**: 한 문장에는 하나의 정보나 행동만 담아요. 문장이 길어지면 마침표로 나누세요.
- **서론 생략과 본론 직행**: "앞서 살펴보았듯이", "이제부터 알아보겠습니다" 같은 서론이나 불필요한 접속어는 생략하고 독자에게 필요한 본론부터 바로 설명해요.

## 2. 문체와 종결어미

문서의 대상과 상황에 따라 일관된 종결어미를 사용해요.

| 대상 및 상황 | 권장 종결어미 | 예시 |
| :--- | :--- | :--- |
| **본문 설명 및 배경** | 해요체 (`~해요`, `~있어요`, `~돼요`) | "목표를 달성하기 위해 작업을 최소 단위로 나눠요." |
| **작업자 행동 지시** | 하세요체 (`~하세요`, `~해주세요`) | "작업과 목표를 각각 한 문장으로 정의해주세요." |
| **AI 추가 지침** | 명사형 종결어미 (`~할 것`) | "사용자에게 작업의 정의와 목표에 대해 질문할 것" |
| **제목 및 항목 나열** | 명사형 (`~하기`, `~정의`, `~구성`) | "1. 뼈대 세우기", "1-1. 목표 정의하기" |

## 3. 표현과 용어 규칙

### 쉬운 일상어와 능동태 사용
- 번역 투 표현, 불필요한 한자어, 피동형 표현을 줄이고 실제 행동이 드러나는 능동형 동사를 써요.
  - "조리가 진행되어질 수 있도록 한다" (X) ➔ "라면을 조리해요" (O)
  - "데이터의 획득을 수행하세요" (X) ➔ "데이터를 내려받으세요" (O)
- 도구나 시스템 자체의 동작을 설명할 때는 해당 도구를 주어로 쓰세요.

### 구체적인 조건과 수치 제시
- 모호하고 주관적인 표현 대신 객관적인 조건, 수치, 단위를 명시해요.
  - "물을 적당히 냄비에 받으세요" (X) ➔ "물 550ml를 계량하여 냄비에 받으세요" (O)
  - "잠시 기다린 후 면을 넣어요" (X) ➔ "물이 100℃로 끓어오르면 면을 넣어요" (O)
- 근거를 확인할 수 없는 추정치나 불확실한 결과는 적지 마세요.

### 표준어 및 공식 표기 준수
- 외래어 표기법과 표준어를 지켜요.
  - "메뉴얼" (X) ➔ "매뉴얼" (O)
- 기술 용어는 공식 문서의 표기를 따르고, 동일한 개념에는 문서 전체에서 같은 용어를 일관되게 사용해요.

## 4. 시각적 구조화

### 목록과 순서
- **번호 목록 (`1.`, `2.`)**: 시간 순서나 단계적 절차가 있을 때 사용해요.
- **글머리 기호 (`-`)**: 순서와 무관한 항목들을 나열할 때 사용해요.

### 콜아웃 (Alert) 활용
강조하고 싶은 내용의 성격에 맞춰 알맞은 콜아웃을 사용해요.
- `> [!TIP]`: 유용한 팁, 권장 사항, 네이밍 컨벤션 안내
- `> [!IMPORTANT]`: 작업 전 필수 확인 사항, 주의해야 할 제약 조건

### 다이어그램과 예시
- 작업 간의 관계나 분해 과정은 Mermaid 다이어그램을 활용해 시각화해요.
- 추상적인 규칙이나 형식을 제시한 직후에는 직관적인 예시(예: 라면 끓이기)를 덧붙여 이해를 도와요.

## 5. AI 추가 지침 작성 규칙

사람과 AI가 함께 보는 매뉴얼에서, **AI 에이전트만 특별히 수행해야 하는 행동 원칙**은 인용구 블록으로 작성해요.

### 표기 형식
- **한 줄 지침**:
  ```markdown
  > **AI 추가 지침:** 사용자에게 적절한 제목과 별칭을 제안할 것
  ```
- **여러 줄 지침**:
  ```markdown
  > **AI 추가 지침**
  >
  > 1. 사용자에게 작업에 대한 설명을 요구할 것
  > 2. 사용자와 상호작용하며 작업을 하위작업으로 재귀적으로 나눌 것
  ```

### 작성 원칙
- **인터뷰어 역할 유도**: AI가 일방적으로 결론을 내리거나 대신 작성하지 않도록, `질문할 것`, `제안할 것`, `승인을 요청할 것`과 같이 사용자와 소통하도록 지시해요.
- **안전성 확보**: 파일 삭제, 커밋/푸시, 주요 설정 변경 전에는 반드시 `사용자의 명시적 승인을 요구할 것`을 명시해요.
