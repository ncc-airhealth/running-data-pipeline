# 4. 개요 작성하기

`SKILL.md`에는 작업의 개요를 작성해요.
해당 매뉴얼을 **한 눈에 파악할 수 있도록** 작성해야해요.

## SKILL.md 템플릿

다음의 템플릿을 기반으로 작성해야해요.

```md
---
name: {{ 매뉴얼 별칭 }}
description: {{ 매뉴얼에 대한 소개 }}
---

# {{ 매뉴얼 제목 }}

{{ 작업의 정의와 목표 }}

## 준비사항

{{ 작업 전 준비사항 }}

## 작업 순서

{{ 작업 순서 }}

```

> [!TIP] 선택 추가 섹션: AI 추가 지침
> AI 에이전트와 함께 작업할 때 AI가 주의하거나 따라야 할 행동 원칙이 있다면 문서 하단에 `> **AI 추가 지침**` 블록을 추가할 수 있어요.

## 4-1. YAML 프론트매터 작성하기

템플릿 상단의 `name`과 `description` 필드를 작성해요.

- `name`: [1. 뼈대 세우기](./1-framework.md)에서 정한 별칭을 기입해요.
- `description`: 매뉴얼에 대한 소개를 한 줄로 작성해요. 매뉴얼을 어떤 상황에서 사용하는지 드러나게 작성하면 좋아요.

> **AI 추가 지침:** 사용자에게 `description` 필드 값을 제안할 것

## 4-2. 매뉴얼 소개 작성하기

템플릿에서 다음의 항목을 작성해요.

- `{{ 매뉴얼 제목 }}`: [1. 뼈대 세우기](./1-framework.md)에서 정한 제목을 기입해요.
- `{{ 작업의 정의와 목표 }}`: [1. 뼈대 세우기](./1-framework.md)에서 제시한 작업의 정의와 목표를 한두 문장으로 소개해 주세요.

> **AI 추가 지침:** 사용자에게 `{{ 작업의 정의와 목표 }}`에 작성할 내용을 제안할 것

## 4-3. 준비사항 작성하기

작업을 시작하기 전에 필요한 준비물이나 사전 지식을 목록으로 정리해요.

- [3. 지식 문서화하기](./3-knowledge.md)에서 정리한 [지식 인덱스](./knowledge/index.md) 문서나 핵심 지식 문서를 링크해요.
- 작업에 필요한 도구, 재료, 권한 또는 사전 준비사항을 안내해요.  
  (예: "준비물: 냄비, 물 550ml, 가스레인지/인덕션, 라면 1봉지")

> **AI 추가 지침:** 사용자에게 선행되어야 할 개발환경이나 필수 권한, 사전 지식 링크를 제안할 것

## 4-4. 작업 순서 작성하기

[2. 워크플로우 설계하기](./2-workflow.md)에서 정리한 작업 목차를 템플릿의 `{{ 작업 순서 }}`에 번호 목록으로 작성해요.

- `SKILL.md`에는 작업의 전체 흐름을 한눈에 볼 수 있도록 **목차 링크만** 배치해요.  
  (예: `1. [물 끓이기](reference/1-boil-water.md)`)
- 각 단계의 구체적인 명령어, 절차, 산출물 등 세부 내용은 다음 단계인 [5. 작업 기술하기](./5-describe.md)에서 개별 문서로 작성해요.

> **AI 추가 지침:** 사용자에게 2단계에서 도출한 워크플로우를 기반으로 `reference/<번호-작업명>.md` 형태의 링크 목록을 구성해 제안할 것
